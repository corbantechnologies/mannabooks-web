# Categories and units

**Categories** group your products (Cement, Paint, Plumbing) so lists are easier to read and the till shows a button per category. A category can sit inside another one.

**Units** are what you sell in: piece, kg, bag, litre, hour. MannaBooks starts you with the common ones.

## Setting them up

1. Open **Sales > Products** and choose **Categories and units**.
2. Add categories and, if you need them, sub-categories.
3. Add any unit you are missing, for example *Bag (bag)*.
4. On each product, choose its category and unit.

Renaming a unit's short form updates every product that uses it. A unit or category in use can't be deleted; mark it inactive instead.

The **KRA eTIMS unit code** is sent to KRA with each line once eTIMS is switched on. Check codes against KRA's code list.
