# Branches

A **branch** is a place you operate from: a shop, an office or a site. Every workspace starts with one, *Head office*, which is the **default** branch.

## Adding a branch

Choose **New branch**, enter a name and a short **code** (for example NRB or MSA). Codes must be different for each branch; they appear on documents and reports.

## The default branch

New records use the default branch unless you pick another. To change it, open another branch and tick **Default branch**. The default branch can't be closed or deleted.

## Closing a branch

Untick **Open** to close a branch you no longer use. Its history stays.

Who can do this: anyone with **Branches: manage** (Owner and Admin by default).
